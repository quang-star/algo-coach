# OLP Tracker V6.1 — Socratic AI Code Review

V6.1 bổ sung workspace review Competitive Programming trên nền V6 AI Coach.

## Tính năng
- Dán statement/constraints, C++17, verdict WA/TLE/RE/MLE và ghi chú.
- AI trả summary, root-cause hypotheses, complexity target, edge cases và 3 tầng hint.
- UI chỉ mở Hint 1 trước; Hint 2/3 do người học chủ động mở.
- Không yêu cầu/khuyến khích full solution mặc định.
- Lưu tối đa 12 review gần nhất trong local-first state và đồng bộ cùng tracker state.
- Có thể chuyển kết luận thành Error Notebook chỉ bằng một nút.
- Edge Function giới hạn code 24k ký tự và statement 5k ký tự.

## Deploy
Giữ nguyên thiết lập V6. Chỉ cần deploy lại function sau khi cập nhật source:

```bash
supabase functions deploy ai-coach
```

Sau đó deploy thư mục `dist/` như V5.5/V6.
